# Напоминания о мероприятиях ВГТУ

Telegram-бот, который присылает двум админам напоминания о мероприятиях программы: за 2 дня, за 1 день и за 2 часа до начала.

В сообщении: название, дата, день недели, время, место, тезисы и спикеры.

## Быстрый запуск

Нужен Python 3.10 или новее. Внешние библиотеки не требуются.

### 1. Создать бота

1. Откройте в Telegram [@BotFather](https://t.me/BotFather).
2. Отправьте `/newbot`, придумайте имя и адрес бота.
3. Скопируйте токен вида `123456789:AA...`.

### 2. Настроить токен

В папке проекта выполните:

```bash
cp .env.example .env
```

Откройте `.env` любым текстовым редактором и вставьте токен в строку `BOT_TOKEN=`.

### 3. Запустить и узнать id чатов

```bash
python3 bot.py
```

В Telegram откройте своего бота, нажмите **Start** и отправьте `/id`. Бот ответит числовым id.

Оба админа должны сделать это сами: Telegram не разрешает писать человеку, который ни разу не открывал бота.

### 4. Вписать админов

В `.env` добавьте id через запятую:

```env
ADMIN_CHAT_IDS=111111111,222222222
```

Остановите бота (`Ctrl+C`) и запустите снова. Проверьте доставку командой `/test` в боте.

## Как работает

Бот проверяет расписание каждые 20 секунд. Напоминание считается наступившим, когда его время прошло, а мероприятие ещё не началось. Если бот был выключен, он отправит одно актуальное напоминание при запуске, но не будет присылать всю пропущенную серию.

Отправленные напоминания запоминаются в `state.json`, поэтому перезапуск не создаёт дублей. Файл можно удалить, чтобы сбросить историю.

## Команды бота

| Команда | Что делает |
| --- | --- |
| `/next` | Ближайшее мероприятие |
| `/schedule` | Все предстоящие мероприятия |
| `/test` | Тестовое напоминание |
| `/status` | Часовой пояс, админы, ближайшее мероприятие |
| `/id` | Ваш числовой id для настройки |
| `/help` | Справка |

## Настройки

Все параметры лежат в `.env`:

| Параметр | По умолчанию | Значение |
| --- | --- | --- |
| `BOT_TOKEN` | — | Токен от @BotFather |
| `ADMIN_CHAT_IDS` | — | Получатели через запятую; можно указать и группу |
| `TIMEZONE` | `Europe/Minsk` | Часовой пояс расписания |
| `REMIND_DAYS` | `2,1` | За сколько дней напоминать |
| `REMIND_AT` | `10:00` | Во сколько отправлять напоминания «за N дней» |
| `REMIND_HOURS` | `2` | За сколько часов напоминать |

Например, чтобы добавить напоминание утром в день мероприятия: `REMIND_DAYS=2,1,0`.

## Расписание

Файл `schedule.json` — основной источник данных. Сейчас в нём:

- 9 занятий с 02.11 по 26.11.2026;
- финал 02.12.2026 (взято из примечания к документу, время 18:00 указано предположительно — поправьте при необходимости).

Не включены:

- строки с 05.10 по 30.10 — в документе выделены красным как уже проведённые;
- 15.12 и 18.12 — в примечании указано, что проводить их не нужно.

### Изменить мероприятие вручную

Откройте `schedule.json` и измените нужное поле:

```json
{
  "id": "2026-11-09",
  "date": "2026-11-09",
  "time": "18:00",
  "title": "Инвест-симуляция",
  "place": "ВГТУ",
  "speakers": ["Мацуганова М.Д.", "Токарь Г.М."],
  "subtitle": "Короткое пояснение",
  "details": "Тезисы занятия",
  "note": "Дополнительная пометка"
}
```

Обязательные поля: `id`, `date`, `time`, `title`. Поле `id` должно быть уникальным. После правки перезапустите бота.

Проверить расчёт напоминаний без запуска бота и без токена:

```bash
python3 bot.py --dry-run --days 60
```

### Пересобрать из нового .docx

Если пришлют обновлённую программу:

```bash
python3 import_docx.py "Программа мероприятий.docx" --year 2026 --out schedule.imported.json
```

Скрипт пропустит красные строки и даты `15.12,18.12`, а диапазоны вида `02.11 – 04.11` разобьёт на отдельные мероприятия. Результат сохранится в `schedule.imported.json` — сравните его с `schedule.json` и перенесите нужные изменения вручную, чтобы не потерять финал 02.12.

## Постоянная работа

Бот должен быть запущен, чтобы отправлять напоминания. Простой вариант на своём Mac:

```bash
nohup python3 bot.py >> bot.log 2>&1 &
```

Остановить: `pkill -f "python3 bot.py"`. Смотреть лог: `tail -f bot.log`.

Если компьютер засыпает или выключается, бот тоже останавливается. Для круглосуточной работы его нужно держать на постоянно включённом компьютере или сервере.

## Файлы

| Файл | Назначение |
| --- | --- |
| `bot.py` | Бот и планировщик напоминаний |
| `schedule.json` | Расписание мероприятий |
| `import_docx.py` | Импорт расписания из `.docx` |
| `.env` | Токен и настройки (не публикуется) |
| `state.json` | История отправленных напоминаний (создаётся автоматически) |

Не выкладывайте `.env` в открытый доступ: по токену можно управлять ботом. Если токен попал не туда, перевыпустите его в @BotFather.
